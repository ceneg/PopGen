# PopGen: population-genomic analyses of SNP data

[![Version](https://img.shields.io/badge/version-1.00-blue.svg)](CHANGELOG.md)
[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.11%2B-blue.svg)](requirements.txt)

Command-line Python scripts for exploratory population genomics of SNP data in
VCF format, written for haploid organisms (such as many fungi). Each script is
independent and produces tables (TSV) and figures (PNG and SVG):

| Script | Analysis |
| --- | --- |
| `scripts/diversity.py` | Pairwise divergence and pairwise differences between samples, with clustered heatmaps |
| `scripts/structure.py` | PCA, DAPC (k-means clusters + LDA) and a UPGMA tree (Newick) |
| `scripts/network.py` | Collapsing of near-identical genotypes and a minimum spanning tree with metadata pie charts |
| `scripts/ld_decay.py` | Linkage disequilibrium (r²) decay with distance and half-decay distance |
| `scripts/selection.py` | Nei–Gojobori dN/dS of each sample against the reference, per gene and genome-wide, drawn on a tree |
| `scripts/recombination.py` | PhiPack recombination tests (PHI, NSS, Max χ²) per contig, Holm-adjusted |
| `scripts/generate_citations.py` | Versions of the Python packages and programs each script uses |

The methods are described in the article that accompanies this software (see
[Citation](#citation)). Two points matter when reading the results: the
divergence values are per *variant* site (not per-bp nucleotide diversity),
and dN/dS between strains of one species does not mean the same as dN/dS
between species.

## Requirements and tested system

Tested on **Ubuntu 24.04.5 LTS (x86_64, Linux kernel 6.8)** with the system
**Python 3.12.3** in a virtual environment (`venv`), the package versions
pinned in [requirements.txt](requirements.txt), and PhiPack 1.1 compiled from
source with GCC 13.3. The example data gave identical results with Python
3.13.3 and the same package versions. Other
systems (other Linux distributions, macOS, Windows) have not been tested.

You need:

* Python 3.11 or newer, with the `venv` module (on Ubuntu:
  `sudo apt install python3-venv`).
* A C compiler, only for building PhiPack, which `recombination.py` uses (on
  Ubuntu: `sudo apt install build-essential`).
* Internet access during installation (Python packages from PyPI, PhiPack
  source code).

Hardware needs depend on the data. The VCF is loaded into memory (plan for
roughly the size of the uncompressed VCF in RAM), and PhiPack needs about
4·*n*² bytes for a contig with *n* informative sites (about 8.6 GB for 46,000
sites).

## Installation

Everything is installed into a `.venv` folder inside the repository; nothing
is installed system-wide.

```bash
git clone https://github.com/ceneg/PopGen.git
cd PopGen
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python tools/install_phipack.py
```

`tools/install_phipack.py` downloads the PhiPack source code (from the
bioconda mirror, or the authors' site if that fails), verifies its SHA-256
checksum, compiles the `Phi` program and puts it into `.venv/bin/`. If the
download fails, download `PhiPack.tar.gz` yourself and run
`.venv/bin/python tools/install_phipack.py --source PhiPack.tar.gz`. PhiPack
is needed only by `recombination.py`; the other scripts work without it.

**Check the installation** by running the tests (under a minute):

```bash
.venv/bin/python -m pytest -q
```

To use the scripts, activate the environment (`source .venv/bin/activate`, so
that `python` is the environment's Python) or call `.venv/bin/python`
directly. The scripts run from the repository folder; there is nothing to
build. To uninstall, delete the repository folder.

## Quick start with the example data

`examples/data/` contains a small **simulated** dataset: 24 haploid samples in
three lineages with some recombination, two contigs with 12 genes, a GFF3
annotation and metadata. It is regenerated by
`python examples/make_example_data.py`. From the repository root, with the
environment activated (`source .venv/bin/activate`):

```bash
python scripts/structure.py --vcf examples/data/example.vcf --meta examples/data/metadata.tsv --out example_run/ex
python scripts/diversity.py --vcf examples/data/example.vcf --meta examples/data/metadata.tsv --out example_run/ex
python scripts/network.py --vcf examples/data/example.vcf --meta examples/data/metadata.tsv --contract 5 --diameter 0.05 --out example_run/ex
python scripts/ld_decay.py --vcf examples/data/example.vcf --out example_run/ex
python scripts/selection.py --vcf examples/data/example.vcf --gff examples/data/example.gff --fasta examples/data/example.fna --nwk example_run/results/ex.upgma.nwk --out example_run/ex
python scripts/recombination.py --vcf examples/data/example.vcf --out example_run/ex
```

The results appear in `example_run/results/`. Expected outcomes: DAPC finds the
three simulated lineages (clusters of 8), dN/dS is close to 1 (the simulated
mutations are random, i.e. neutral), LD falls to half its maximum at about
6 kb, and PHI detects recombination on both contigs.

## Usage

All scripts print `--help`. Input formats are described in
[docs/input_formats.md](docs/input_formats.md): the VCF must be biallelic,
and the metadata is a tab-separated file with a `strain` column.

**Output location.** `--out DIR/NAME` writes the tables to
`DIR/results/NAME.*` and the figures to `DIR/results/png/` and
`DIR/results/svg/`. A bare `--out NAME` writes to `./results/`. Existing files
with the same names are overwritten.

**Logs.** Every run writes its command, parameters, Python and package versions
and messages to `logs/<script>_<timestamp>_<pid>.log` in the repository, or to
the directory named by the environment variable `POPGEN_LOG_DIR`.

### diversity.py

```bash
python scripts/diversity.py --vcf VCF --meta META --out PREFIX
```

Writes `PREFIX.nd.tsv` (pairwise divergence per variant site) and
`PREFIX.ss.tsv` (number of differing sites), and a heatmap of each, plain and
with a colour bar for each metadata column.

### structure.py

```bash
python scripts/structure.py --vcf VCF --meta META --out PREFIX
```

Writes PCA and DAPC coordinates (`PREFIX.pca.tsv`, `PREFIX.dapc.tsv`), scatter
plots per metadata column with and without 95% ellipses, the DAPC clusters, and
the UPGMA tree (`PREFIX.upgma.nwk` and a dendrogram).

### network.py

```bash
python scripts/network.py --vcf VCF [--meta META] [--contract N] [--distances K] [--diameter D] [--out PREFIX]
```

* `--contract N`: collapse samples that differ at no more than N sites
  (default 0: only identical genotypes).
* `--distances K`: spring-layout node spacing (networkx `k`, default 1.0).
* `--diameter D`: radius of the largest pie chart in layout units (default
  0.001, which is very small; values around 0.02–0.1 are usually visible).

Writes the genotype groups (`PREFIX.genotype_summary.txt`) and one figure per
metadata column (`PREFIX.<column>.msn.png/svg`).

### ld_decay.py

```bash
python scripts/ld_decay.py --vcf VCF --out PREFIX [--window BP] [--bin-size BP] [--min-samples N] [--subset FRACTION]
```

Defaults: 10,000 bp window, 100 bp bins, at least 2 samples with the alternate
allele, all variants. Writes binned mean r² (`PREFIX.ld_decay.tsv`) and the
decay plot; the half-decay distance is logged.

### selection.py

```bash
python scripts/selection.py --vcf VCF --gff GFF --fasta FASTA --nwk TREE.nwk --out PREFIX
```

The tree can be the `upgma.nwk` from `structure.py`. Writes per-gene values for
genes that differ from the reference (`PREFIX.tsv`), genome-wide values per
sample (`PREFIX.summary.tsv`: dN, dS, dN/dS, pN, pS and the underlying counts)
and the tree annotated with dN, dS and dN/dS. Uses all CPU cores but one.

### recombination.py

```bash
python scripts/recombination.py --vcf VCF --out PREFIX [--jobs N] [--max-ram GB] [--resume] [--min-snps N] [--max-informative N] [--subset FRACTION]
```

Requires PhiPack's `Phi` (installed by `tools/install_phipack.py` into
`.venv/bin/`, or found on the `PATH`). Writes a per-contig table
(`PREFIX.phi.contigs.tsv`), a summary (`PREFIX.phi.summary.txt`) and Phi's
output for each contig (`PREFIX.phi.logs/`). Phi's permutation tests can take
hours for contigs with tens of thousands of informative sites; `--resume`
reuses finished contigs after an interruption.

### generate_citations.py

```bash
python scripts/generate_citations.py [--out FILE]
```

Lists the package and program versions used by each script (default
`results/citations.txt` in the current directory).

## Repository layout

```
scripts/      command-line analyses (one per analysis)
src/          shared code: VCF reading, distances, logging (utils.py),
              Nei-Gojobori counting (dnds.py), input checks (validators.py)
tests/        pytest suite (unit tests and end-to-end runs on the example data)
tools/        PhiPack installer
examples/     simulated example dataset and the script that generates it
docs/         input formats
CHANGELOG.md  release notes
```
